# Capturas de instalación en Supabase

La base de datos no se ha instalado en un proyecto remoto, por lo que este directorio no debe contener imágenes simuladas. Después de ejecutar `supabase_rassa.sql` en el proyecto Supabase del equipo, guardar aquí:

1. `01-tablas.png` — Database → Table Editor mostrando las tablas de `public`.
2. `02-diagrama-supabase.png` — Database → Schema Visualizer con las relaciones.
3. `03-rls.png` — detalle de políticas RLS de pedidos y mensajes.
4. `04-storage.png` — bucket privado `chat-images` y límites de carga.

Ocultar URL del proyecto, claves, correos personales y cualquier dato real de usuario antes de compartir las capturas.
